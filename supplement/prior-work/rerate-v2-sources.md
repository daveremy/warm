Rate each of the eight sources on C1 to C4. Read the primary source. If a location refuses you, say so and say what you read instead.

1. **AAM/5C.** Laurent Goujon, "Agentic Architecture of Information Systems. The AAM/5C Model: A Reference Model for Distributed Autonomy", arXiv:2610.30221. https://arxiv.org/abs/2610.30221
2. **OperA.** Virginia Dignum, Frank Dignum and John-Jules Meyer, "An agent-mediated approach to the support of knowledge sharing in organizations", The Knowledge Engineering Review 19(2):147-174, 2004. https://www.maxapress.com/data/article/ker/preview/pdf/S0269888904000244.pdf
3. **ASOC.** Beheshti et al., "Agentic Service-Oriented Computing: A Manifesto for the Next Frontier of Service-Oriented Computing", arXiv:2607.12619. https://arxiv.org/html/2607.12619
4. **Microsoft Multi-Agent Reference Architecture.** https://github.com/microsoft/multi-agent-reference-architecture (the earlier reading used commit adbefc1; files such as Agent-Registry.md, Reference-Architecture.md, Patterns.md).
5. **Horling and Lesser**, "A Survey of Multi-Agent Organizational Paradigms" (2004). https://posomas.isse.de/PosoMAS-Scrum/aose.practice.tech.agent_organisation_design.base/guidances/whitepapers/resources/Bryan%20Horling%20and%20Victor%20Lesser%20-%20A%20Survey%20of%20Multi-Agent%20Organizational%20Paradigms.pdf
6. **FIPA Agent Management Specification SC00023K.** fipa.org refuses automated requests. A text extraction of a 2015 Wayback Machine capture is at scratch/src/fipa-SC00023K-text.txt (it starts with a table of contents and shows some tracked-change residue; the body starts at "2 Agent Management Reference Model Agent management provides"). Capture URL: https://web.archive.org/web/2015id_/http://www.fipa.org/specs/fipa00023/SC00023K.html
7. **Electronic institutions: ISLANDER and AMELI**, rated as one source. Esteva, Rosell, Rodríguez-Aguilar and Arcos, "AMELI: An Agent-based Middleware for Electronic Institutions", AAMAS 2004: scratch/src/ameli.pdf (https://www.iiia.csic.es/media/filer_public/b8/a0/b8a0f2a8-6ab7-49af-a6b8-597b95af9c18/iiia-2004-896.pdf). Huget, Esteva, Phelps, Sierra and Wooldridge, "Model Checking Electronic Institutions", section 2: scratch/src/huget-model-checking-EI.pdf. The ISLANDER article itself (AAMAS 2002, pp. 1045-1052) if you can find an open copy.
8. **JaCaMo.** Boissier, Bordini, Hübner, Ricci and Santi, "Multi-agent oriented programming with JaCaMo", Science of Computer Programming 78(6), 2013, DOI 10.1016/j.scico.2011.10.004, if you can open it (the publisher refused this machine). Otherwise the project's own material: https://jacamo-lang.github.io/ , the ORA4MAS reference (github.com/moise-lang/moise, doc/ora4mas/readme.adoc; `gh api repos/moise-lang/moise/contents/doc/ora4mas/readme.adoc --jq .content | base64 -d`), the Moise specification (same repository, doc/specification/moise-spec.pdf), and the API pages under https://moise-lang.github.io/doc/api/ora4mas/nopl/ (GroupBoard, SchemeBoard, OrgBoard, NormativeBoard). Say which you read.
