## Evidence

One line for every yes, part and no cell: the column, the value, the file and line in the notes, and a short quotation from that line. For a "part" cell the words after "missing:" say what is missing, in eight words or fewer; for cells taken from a reverse-direction table these words summarize the rest of the same table row.

**How the lines were made and checked.** A script parsed the reverse-direction tables to take each service's verdict, line number and cell text. The cells those tables do not cover were entered by hand as a file and a quotation. The script then located each quotation in its file (it stopped if a quotation matched no line or more than one line in the stated range), and a second pass re-read every cited line and confirmed that it exists and contains the quoted words, that every "part" cell has a note of what is missing, and that no note is longer than eight words. All 533 evidence lines passed. Quotations may be cut at a word boundary; they are never altered.
