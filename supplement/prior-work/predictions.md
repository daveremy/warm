# Predictions before the systematic review (sagan, 2026-11-11 16:00, written before any mapping of a reference model to WARM v0.11)

Scope: reference models, reference architectures and taxonomies of agent systems (vendor or not), each mapped component by component to WARM v0.11.

| # | Prediction |
|---|---|
| R1 | At least 80% of each source's named components map to one WARM service, layer or domain part |
| R2 | No source has a directory of which area of work is accountable for what |
| R3 | No source gives an area of work a charter with its own workflow and acceptance criteria |
| R4 | Misfits concentrate in three places: event and messaging infrastructure, the client or experience layer, and business design or requirements |
| R5 | At least two sources have a part WARM v0.11 lacks at the level of a service; my guesses: context or prompt management, safety guardrails apart from policy, cost management, human oversight roles |
| R6 | At least one source splits a WARM service in two in a way that looks right (most likely Harness, Orchestration or Policy) |
| R7 | No source contradicts WARM's two cross-cutting groups, but at least one makes Observability or Security a layer and not a cross-cutting concern |
| R8 | The review changes the model in 2 to 5 places, fewer than the platform mapping's 11 |

## Round 2 predictions (sagan, 2026-11-11 16:25, written before any round-2 mapping; I have read only the search reader's one-line summaries of these sources)
| # | Prediction |
|---|---|
| S1 | Charterion's "charter" and AEON's "subdomain" will each turn out to bound ONE agent's authority or one capability, not an area of work whose roles several agents and people fill |
| S2 | None of the eight has a directory of which area of work is accountable for what |
| S3 | AOS's persistent identity versus transient instance will match WARM's agent versus definition distinction, and will NOT be the same as WARM's persistent agent versus task agent |
| S4 | CEAD's "define the business capability and owner before the agent" will be the closest precedent for WARM's "a domain defines roles, agents fill them" |
| S5 | Round 2 changes the model in at most 3 further places; cost management becomes a named concern |
