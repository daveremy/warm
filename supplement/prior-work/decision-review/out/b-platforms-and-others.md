# Further passages

Passages that treat reducing people's decisions as a goal:

- OpenClaw, standing orders: "Standing orders grant your agent permanent operating authority for defined programs. Instead of prompting the agent for each task, you define programs with clear scope, triggers, and escalation rules, and the agent executes autonomously within those boundaries" (docs.openclaw.ai/automation/standing-orders).
- OpenClaw release notes 2026.9.5, Security and Privacy: "Reduce approval prompts caused by truncated command reviews [#144587]" (docs.openclaw.ai/releases/2026.9.5).
- LangChain Deep Agents Code: Auto mode "Approves routine actions automatically; asks the model to review anything uncertain" (oss/deepagents/code/approval-modes). This replaces some approvals by people with a model review.
- AgentCore: "Amazon Bedrock AgentCore Browser reduces CAPTCHA challenges through Web Bot Auth" (CAPTCHA Reduction). This reduces capability hand-offs, not approvals.
- Xia, EDDOps: "Selective escalation and periodic calibration contain cost. Several sources describe patterns in which automated evaluation is used by default, with escalation to human review triggered by signals such as uncertainty, disagreement between models, or potential harm" (Section 4, PDF pp. 12-13). The decisions here are evaluations, not approvals of actions.
- Hua cites, without endorsing: "Shapiro's five levels end in a 'dark factory' in which humans neither write nor review code" (Section 2, PDF p. 3). For System F: "the operator reviews only intent and acceptance evidence, while repair budgets, failure classification and back-off are automated" (PDF p. 9).

Passages that say people's decisions should not be reduced:

- WorkMate: "final decision-making authority over high-risk operations must remain under human control" and "final authority consistently remains under human supervision" (Section 6.2, PDF p. 17).
- Xia, EDDOps, driver D6: "humans retain evaluative agency over ambiguous, high-impact, or contested cases" (Section 4, PDF p. 13).
- Microsoft CAF: "mandate human-in-the-loop confirmation for high-impact actions like database writes or financial transactions. This control prevents autonomous errors and ensures accountability" (Tools section).
- LangChain Deep Agents Code: "Auto is an authorization heuristic for a local coding agent. It is not sandbox containment" and "High-risk effects ... still require explicit authorization" (approval-modes). A caution, not a rule against reduction.
